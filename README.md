# Media Share API - Landing Page

A modern, responsive landing page for Media Share API built with Next.js, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Hero Section** with animated gradient background and platform icons
- **Key Features** showcasing 7 core API capabilities with code examples
- **Use Cases** for agencies, SaaS products, e-commerce, and content creators
- **Supported Platforms** table with live/coming soon status
- **Pricing Section** with 4 tiers (Free, Starter, Professional, Enterprise)
- **Developer Experience** with code examples in Node.js, Python, and cURL
- **Stats & Testimonials** with social proof
- **Contact & Support** section with multiple support channels
- **Comprehensive Footer** with all links and newsletter signup
- **Fully Responsive** design for mobile, tablet, and desktop
- **Smooth Animations** using Framer Motion
- **Dark Mode Support**

## 📋 Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Language:** JavaScript (ES6+)

## 🛠️ Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd media-share-landing
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📦 Build for Production

```bash
npm run build
npm start
```

## 🎨 Customization

### Colors
The color scheme is defined in `tailwind.config.js`:
- Primary: `#667eea` (Purple/Blue)
- Secondary: `#764ba2` (Purple)
- Success: `#10b981` (Green)
- Warning: `#f59e0b` (Orange)
- Error: `#ef4444` (Red)

### Content
All content can be modified directly in the component files:
- `components/Hero.js` - Hero section
- `components/Features.js` - Features section
- `components/UseCases.js` - Use cases
- `components/Platforms.js` - Supported platforms
- `components/Pricing.js` - Pricing tiers
- `components/DeveloperExperience.js` - Code examples
- `components/StatsTestimonials.js` - Stats and testimonials
- `components/ContactSupport.js` - Contact information
- `components/Footer.js` - Footer links
